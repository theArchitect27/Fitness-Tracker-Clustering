
# Clustering Fitness Tracker Data

## Problem
Understanding user behaviour from raw fitness data is difficult without structured analysis.

## Solution
This project uses KMeans clustering to group users based on activity (steps per day) and sleep patterns.

## Approach
- Generated simulated data for three user groups
- Applied clustering using KMeans
- Visualised results using scatter plots

## Results
The model successfully identified:
- Active users (high steps, good sleep)
- Moderately active users
- Least active users

## Technologies
- Python
- NumPy
- Matplotlib
- Scikit-learn

- Improved analytical thinking
